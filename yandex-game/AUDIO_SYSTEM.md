# Система звука в игре

## Обзор

В игру добавлена полная система управления звуком с поддержкой:
- Фоновой музыки
- Звуковых эффектов
- Настроек звука (включение/выключение)
- Автоматической паузы при сворачивании окна/вкладки

## Реализованные компоненты

### 1. AudioService (`src/services/audioService.ts`)

Singleton-сервис для управления всеми звуками в игре.

**Основные методы:**
- `init(scene)` - инициализация сервиса с текущей сценой Phaser
- `playBackgroundMusic(key)` - запуск фоновой музыки
- `playSound(key, volume)` - воспроизведение звукового эффекта
- `toggleMute()` - переключение звука вкл/выкл
- `setMuted(boolean)` - установка состояния звука
- `getMuted()` - получение текущего состояния звука

**Функции:**
- Сохранение настроек звука в localStorage
- Автоматическая пауза при сворачивании окна браузера
- Автоматическая пауза при переключении на другую вкладку
- Поддержка Page Visibility API и blur/focus событий

### 2. SettingsScene (`src/scenes/SettingsScene.ts`)

Новая сцена с настройками игры.

**Возможности:**
- Переключение звука (Включен/Выключен)
- Визуальная индикация состояния (зеленая кнопка = вкл, красная = выкл)
- Адаптивная верстка для портретного и ландшафтного режимов
- Полная поддержка двух языков (русский/английский)

### 3. Интеграция в главное меню

Добавлена кнопка "Настройки" в MenuScene:
- Портретный режим: кнопка в списке главных кнопок
- Ландшафтный режим: кнопка справа
- Автоматическое позиционирование с учётом гостевого режима

### 4. Обработка видимости страницы

Реализована в двух местах:
1. **AudioService** - управляет паузой/возобновлением через свои методы
2. **main.ts** - дублирующая обработка для совместимости (может быть удалена в будущем)

Звук автоматически останавливается при:
- Сворачивании окна браузера
- Переключении на другую вкладку
- Открытии меню выбора вкладок

### 5. Переводы

Добавлены ключи в `src/i18n/translations.ts`:
- `menuSettings` - "Настройки" / "Settings"
- `settingsTitle` - "Настройки" / "Settings"
- `settingsSound` - "Звук" / "Sound"
- `settingsSoundOn` - "Включен" / "On"
- `settingsSoundOff` - "Выключен" / "Off"

## Добавление звуковых файлов

### Структура папок (рекомендуемая)

```
public/assets/audio/
├── music/
│   └── background-music.mp3
└── sounds/
    ├── click.mp3
    ├── spin.mp3
    ├── win.mp3
    ├── case-open.mp3
    └── button.mp3
```

### Загрузка звуков

В файле `src/scenes/PreloadScene.ts` раскомментируйте и дополните секцию загрузки:

```typescript
// Музыка
this.load.audio("bgMusic", "assets/audio/music/background-music.mp3");

// Звуковые эффекты
this.load.audio("click", "assets/audio/sounds/click.mp3");
this.load.audio("spin", "assets/audio/sounds/spin.mp3");
this.load.audio("win", "assets/audio/sounds/win.mp3");
this.load.audio("caseOpen", "assets/audio/sounds/case-open.mp3");
this.load.audio("button", "assets/audio/sounds/button.mp3");
```

### Воспроизведение звуков

```typescript
import { audioService } from "../services/audioService";

// Фоновая музыка (запускается один раз при старте игры)
audioService.playBackgroundMusic("bgMusic");

// Звуковые эффекты
audioService.playSound("click"); // обычная громкость
audioService.playSound("win", 0.8); // 80% громкости
```

## Где добавить звуки

### MenuScene
```typescript
create() {
  // Запустить фоновую музыку при первом входе в меню
  audioService.playBackgroundMusic("bgMusic");
}

// При нажатии на кнопки
addTextButton(this, x, y, text, () => {
  audioService.playSound("button");
  // ... остальная логика
});
```

### SpinScene
```typescript
// При старте спина
playSpinAnimation(onDone) {
  audioService.playSound("spin");
  // ... анимация
}

// При получении хорошей машины
finishSpin() {
  const car = spin(CARS, save.chanceLevel);
  if (car.rarity === "Легендарный" || car.rarity === "Эксклюзивный") {
    audioService.playSound("win");
  }
}
```

### CasesScene
```typescript
// При открытии кейса
openSingle(definition) {
  audioService.playSound("caseOpen");
  // ... логика открытия
}
```

### GarageScene, UpgradesScene
```typescript
// При нажатии на кнопки
audioService.playSound("click");
```

## Генерация звуковых эффектов

Если у вас нет готовых звуков, можно использовать бесплатные онлайн-генераторы:

1. **jsfxr** (https://sfxr.me/) - для игровых звуковых эффектов
2. **Bfxr** (https://www.bfxr.net/) - для ретро звуков
3. **Freesound** (https://freesound.org/) - база бесплатных звуков
4. **Incompetech** (https://incompetech.com/music/) - бесплатная музыка

## Тестирование

1. Запустите игру локально
2. Проверьте кнопку "Настройки" в главном меню
3. Переключите звук вкл/выкл
4. Проверьте сохранение настроек (перезагрузите страницу)
5. Проверьте автопаузу:
   - Сверните окно браузера
   - Переключитесь на другую вкладку
   - Откройте меню выбора вкладок (Ctrl+Tab)

## Соответствие требованиям Yandex Games

✅ Звук останавливается при сворачивании окна браузера  
✅ Звук останавливается при переключении на другую вкладку  
✅ Звук останавливается в меню выбора вкладок  
✅ Настройки звука сохраняются между сессиями  
✅ Пользователь может отключить звук в настройках
