# 🎵 Инструкция по генерации звуковых файлов

## Быстрый старт

Для добавления звуков в игру выполните один из следующих способов:

### Способ 1: Python скрипт (рекомендуется)

```bash
cd yandex-game
python generate-audio.py
```

Этот скрипт автоматически создаст все необходимые звуковые файлы в формате WAV.

### Способ 2: Node.js скрипт

```bash
cd yandex-game
node generate-audio.js
```

### Способ 3: HTML генератор (браузер)

1. Откройте файл `generate-audio.html` в браузере
2. Нажмите кнопку "Сгенерировать все звуки"
3. Нажмите "Скачать все (ZIP)"
4. Распакуйте архив в папку `public/assets/audio/`

---

## Что будет создано

После выполнения скрипта в папке `public/assets/audio/` появятся следующие файлы:

```
public/assets/audio/
├── music/
│   └── background-music.wav  (фоновая музыка, 8 сек. loop)
└── sounds/
    ├── click.wav             (короткий клик)
    ├── button.wav            (мягкий звук кнопки)
    ├── spin.wav              (звук вращения спина)
    ├── win.wav               (звук выигрыша)
    └── case-open.wav         (звук открытия кейса)
```

## Что уже сделано в коде

### ✅ Загрузка звуков в PreloadScene

Звуки автоматически загружаются при старте игры:

```typescript
// Музыка
this.load.audio("bgMusic", "assets/audio/music/background-music.wav");

// Звуковые эффекты
this.load.audio("click", "assets/audio/sounds/click.wav");
this.load.audio("button", "assets/audio/sounds/button.wav");
this.load.audio("spin", "assets/audio/sounds/spin.wav");
this.load.audio("win", "assets/audio/sounds/win.wav");
this.load.audio("caseOpen", "assets/audio/sounds/case-open.wav");
```

### ✅ Интеграция звуков в сцены

**MenuScene:**
- Фоновая музыка запускается при входе в меню
- Звук кнопки при каждом нажатии

**SpinScene:**
- Звук вращения при запуске спина
- Звук выигрыша для редких машин (Эпический, Легендарный, Эксклюзивный)

**CasesScene:**
- Звук открытия кейса при каждом открытии

**GarageScene, UpgradesScene, SettingsScene:**
- Звук кнопки при нажатиях

**SettingsScene:**
- Переключение звука вкл/выкл
- Тестовый звук при включении

### ✅ AudioService

Сервис управляет всеми звуками:
- Автоматическая пауза при сворачивании окна/вкладки
- Сохранение настроек в localStorage
- Управление фоновой музыкой и эффектами

## Проверка работы

1. **Сгенерируйте звуки** одним из способов выше
2. **Запустите игру:**
   ```bash
   npm run dev
   ```
3. **Проверьте:**
   - Фоновая музыка играет в главном меню
   - Кнопки издают звук при нажатии
   - Спин издает звук вращения
   - Редкие машины издают звук выигрыша
   - Открытие кейса издает звук

4. **Проверьте настройки:**
   - Откройте меню "Настройки"
   - Отключите звук - все звуки должны остановиться
   - Включите звук - должен проиграться тестовый клик

5. **Проверьте автопаузу:**
   - Сверните окно браузера - звук должен остановиться
   - Переключитесь на другую вкладку - звук должен остановиться
   - Вернитесь обратно - звук должен возобновиться

## Альтернатива: использование своих звуков

Если вы хотите использовать собственные звуковые файлы:

1. Подготовьте файлы в формате WAV или MP3
2. Разместите их в соответствующих папках:
   ```
   public/assets/audio/music/background-music.wav
   public/assets/audio/sounds/click.wav
   public/assets/audio/sounds/button.wav
   public/assets/audio/sounds/spin.wav
   public/assets/audio/sounds/win.wav
   public/assets/audio/sounds/case-open.wav
   ```
3. Запустите игру - звуки загрузятся автоматически

### Рекомендации для звуковых файлов:

- **Формат:** WAV (без сжатия) или MP3 (для экономии места)
- **Sample Rate:** 44100 Hz
- **Bit Depth:** 16-bit
- **Каналы:** Mono для эффектов, Stereo для музыки

**Длительность:**
- click.wav: ~100ms
- button.wav: ~80ms
- spin.wav: ~1.5s
- win.wav: ~800ms
- case-open.wav: ~600ms
- background-music.wav: 8-15 секунд (будет зациклена)

## Troubleshooting

### Звуки не загружаются

**Проблема:** В консоли браузера ошибки загрузки файлов

**Решение:**
1. Проверьте, что файлы находятся в правильных папках
2. Проверьте имена файлов (они должны совпадать с кодом)
3. Убедитесь, что путь `public/assets/audio/` существует

### Звуки не воспроизводятся

**Проблема:** Файлы загрузились, но не играют

**Решение:**
1. Проверьте настройки звука в игре (Меню → Настройки)
2. Проверьте громкость браузера/системы
3. Попробуйте другой браузер (Chrome рекомендуется)
4. Откройте консоль браузера и проверьте ошибки

### Музыка не зацикливается

**Проблема:** Фоновая музыка играет один раз и останавливается

**Решение:**
Код уже настроен на зацикливание. Если проблема сохраняется:
1. Проверьте длину аудиофайла (минимум 5 секунд)
2. Убедитесь, что файл не поврежден
3. Попробуйте пересоздать файл

### Звук не останавливается при сворачивании

**Проблема:** Звук продолжает играть в фоне

**Решение:**
Page Visibility API поддерживается всеми современными браузерами.
Проверьте консоль на наличие ошибок JavaScript.

## Техническая информация

### Как работает система звука

1. **PreloadScene** загружает все звуковые файлы при старте
2. **AudioService** управляет воспроизведением и состоянием
3. **Page Visibility API** отслеживает видимость вкладки
4. **localStorage** сохраняет настройки звука

### Интеграция с Yandex Games

Система звука соответствует требованиям Yandex Games SDK:
- ✅ Автоматическая пауза при сворачивании
- ✅ Пауза при переключении вкладки
- ✅ Настройка звука доступна пользователю
- ✅ Звук не мешает рекламе

## Дополнительная настройка

### Изменение громкости звуков

Откройте `src/services/audioService.ts` и измените значения:

```typescript
// Для фоновой музыки
this.bgMusic = this.scene.sound.add(key, {
  loop: true,
  volume: 0.3  // 30% громкости (измените на 0.1 - 1.0)
});

// Для звуковых эффектов
playSound(key: string, volume: number = 0.5) {  // 50% по умолчанию
```

### Добавление новых звуков

1. Добавьте загрузку в `PreloadScene.ts`:
   ```typescript
   this.load.audio("mySound", "assets/audio/sounds/my-sound.wav");
   ```

2. Воспроизведите в нужном месте:
   ```typescript
   audioService.playSound("mySound");
   ```
