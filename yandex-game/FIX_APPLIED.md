# Исправление: Добавлен импорт Phaser в audioService

## Проблема
В билде игры не работал звук и не появлялась кнопка настроек.

## Причина
В файле `src/services/audioService.ts` отсутствовал импорт `Phaser`, из-за чего TypeScript не мог скомпилировать код, и весь модуль не работал.

## Исправление
Добавлен импорт в начало файла `src/services/audioService.ts`:
```typescript
import Phaser from "phaser";
```

## Что теперь должно работать

### ✅ Кнопка настроек в главном меню
- **Портретный режим:** Кнопка "Настройки" внизу списка кнопок
- **Ландшафтный режим:** Кнопка "Настройки" в правой панели

### ✅ Сцена настроек
- Открывается при нажатии на кнопку "Настройки"
- Показывает переключатель звука (Включен/Выключен)
- Зелёная кнопка = звук включен
- Красная кнопка = звук выключен

### ✅ Звуковые эффекты
- **Фоновая музыка:** Играет в главном меню (если звук включен)
- **Клик кнопки:** При нажатии на любую кнопку
- **Спин:** При запуске вращения
- **Выигрыш:** При получении редкой машины (Эпический, Легендарный, Эксклюзивный)
- **Открытие кейса:** При открытии любого кейса

### ✅ Автоматическая пауза звука
- При сворачивании окна браузера
- При переключении на другую вкладку
- При открытии меню выбора вкладок
- При возврате - звук возобновляется автоматически

## Следующий шаг

Пересоберите проект:
```bash
npm run build
```

Или запустите dev-сервер:
```bash
npm run dev
```

Звук и кнопка настроек должны теперь работать!

## Проверка работы

1. **Запустите игру**
2. **Проверьте главное меню:**
   - Должна играть фоновая музыка
   - Должна быть видна кнопка "Настройки" / "Settings"
3. **Откройте настройки:**
   - Нажмите на кнопку настроек
   - Должна открыться новая сцена с переключателем звука
4. **Проверьте переключение звука:**
   - Нажмите на кнопку звука - музыка должна остановиться
   - Кнопка должна стать красной с текстом "Выключен" / "Off"
   - Нажмите снова - музыка должна возобновиться
   - Кнопка должна стать зелёной с текстом "Включен" / "On"
5. **Проверьте автопаузу:**
   - Сверните окно - звук должен остановиться
   - Разверните окно - звук должен возобновиться

Если всё работает - исправление успешно применено! 🎉
