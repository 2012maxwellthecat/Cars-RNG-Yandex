# Проблемы соответствия требованиям Yandex Games

Дата проверки: 2026-07-30  
Проверенная документация: https://yandex.ru/dev/games/doc/ru/concepts/requirements

## ❌ КРИТИЧЕСКИЕ ПРОБЛЕМЫ (блокируют публикацию)

### 1. LoadingAPI.ready() не вызывается
**Требование:** 1.14  
**Проблема:** После загрузки ассетов игра должна вызвать `ysdk.features.LoadingAPI.ready()`, чтобы уведомить Яндекс о готовности к показу.

**Текущее состояние:**
- Вызов отсутствует в `PreloadScene.ts`
- Яндекс не узнает, что игра полностью загружена

**Что нужно исправить:**
- В `PreloadScene.ts` метод `create()` добавить вызов `ysdk.features.LoadingAPI.ready()`
- Добавить обработку ошибок (SDK может быть недоступен)

**Файлы:** `src/scenes/PreloadScene.ts`

---

### 2. Звук игры не останавливается при показе рекламы
**Требование:** 4.4  
**Проблема:** При показе fullscreen рекламы все звуки игры должны быть поставлены на паузу.

**Текущее состояние:**
- `advertisementService.ts` не управляет звуком Phaser
- Звук игры накладывается на звук рекламы

**Что нужно исправить:**
- В `showFullscreenAd()` перед показом рекламы: `scene.sound.pauseAll()`
- После закрытия рекламы: `scene.sound.resumeAll()`
- Передавать ссылку на текущую сцену в advertisement service

**Файлы:** `src/services/advertisementService.ts`

---

### 3. Типы LoadingAPI отсутствуют
**Требование:** 1.14  
**Проблема:** В TypeScript типах отсутствует `features.LoadingAPI`

**Текущее состояние:**
- `yandex-games.d.ts` содержит только Player, Leaderboards, adv
- TypeScript выдаст ошибку при попытке вызвать `LoadingAPI.ready()`

**Что нужно исправить:**
- Добавить в `YandexGamesSdk` тип:
```typescript
features?: {
  LoadingAPI?: {
    ready(): void;
  };
};
```

**Файлы:** `src/types/yandex-games.d.ts`

---

### 4. Отсутствует обработка visibilitychange для паузы звука
**Требование:** 1.9  
**Проблема:** При сворачивании вкладки/игры звук должен автоматически останавливаться.

**Текущее состояние:**
- Нет слушателя `document.addEventListener('visibilitychange')`
- Звук продолжает играть в фоновой вкладке

**Что нужно исправить:**
- В `main.ts` или `BootScene.ts` добавить:
```typescript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    game.sound.pauseAll();
  } else {
    game.sound.resumeAll();
  }
});
```

**Файлы:** `src/main.ts` или `src/scenes/BootScene.ts`

---

### 5. Нет гостевого входа (авторизация обязательна)
**Требование:** 1.3  
**Проблема:** Игра должна работать без авторизации, но с ограниченным функционалом (нет облачных сохранений, лидербордов).

**Текущее состояние:**
- `yandexSdk.init()` вызывает `getPlayer({ scopes: false })`
- Нет обработки случая, когда пользователь отказывается от авторизации
- Игра может не запуститься для неавторизованных

**Что нужно исправить:**
- Обернуть `getPlayer()` в try-catch
- Если ошибка авторизации — продолжить работу с локальными сохранениями
- Скрыть кнопку "Лидерборд" для неавторизованных

**Файлы:** `src/services/yandexSdk.ts`, `src/scenes/MenuScene.ts`

---

### 6. Mock SDK не имеет LoadingAPI
**Требование:** 1.14  
**Проблема:** Mock SDK не содержит `features.LoadingAPI` для локальной разработки.

**Текущее состояние:**
- `public/sdk.js` содержит только Player, Leaderboards, adv
- Локальная разработка не тестирует вызов `LoadingAPI.ready()`

**Что нужно исправить:**
- Добавить в mock SDK:
```javascript
features: {
  LoadingAPI: {
    ready: () => {
      console.log('[MOCK SDK] LoadingAPI.ready() вызван');
    }
  }
}
```

**Файлы:** `public/sdk.js`

## ⚠️ ВАЖНЫЕ ПРОБЛЕМЫ (могут вызвать вопросы при модерации)

### 7. Нет автоопределения языка через SDK
**Требование:** 2.14  
**Проблема:** Игра должна определять язык интерфейса через `ysdk.environment.i18n.lang`

**Текущее состояние:**
- Язык жестко задан в `index.html`: `<html lang="ru">`
- Иностранные пользователи видят только русский интерфейс

**Что нужно исправить:**
- В `yandexSdk.init()` получить `ysdk.environment.i18n.lang`
- Загружать соответствующие тексты (если планируется локализация)
- Если локализации нет — оставить как есть, но указать в описании игры "только русский язык"

**Файлы:** `src/services/yandexSdk.ts`, `index.html`

### 9. Fullscreen реклама может показываться слишком часто
**Требование:** 4.3  
**Проблема:** Реклама должна показываться в логических паузах, не чаще раз в 3-5 минут.

**Текущее состояние:**
- `MenuScene`: каждые 4 перехода + cooldown 3 мин ✅
- `GarageScene`: 30% вероятность + cooldown 5 мин ⚠️
- `LeaderboardScene`: 25% вероятность + cooldown 5 мин ⚠️
- `CasesScene` (bulk 100): cooldown 4 мин ✅
- `SpinScene` (autospin): cooldown 5 мин ✅

**Что проверить:**
- Если игрок часто заходит в Garage/Leaderboard, реклама может раздражать
- Рекомендуется увеличить cooldown до 5-7 минут или убрать из одной из сцен

**Файлы:** `src/scenes/GarageScene.ts`, `src/scenes/LeaderboardScene.ts`

---

### 10. Отсутствует обработка ошибок инициализации SDK
**Требование:** 1.15  
**Проблема:** Если SDK не загрузился или инициализация упала, игра должна продолжить работу.

**Текущее состояние:**
- `yandexSdk.init()` просто делает `return` если `window.YaGames` отсутствует
- Ошибки внутри `YaGames.init()` не обрабатываются

**Что нужно исправить:**
- Обернуть весь `yandexSdk.init()` в try-catch
- Логировать ошибки, но не останавливать загрузку игры
- Показывать уведомление "Игра работает в офлайн режиме" (опционально)

**Файлы:** `src/services/yandexSdk.ts`, `src/scenes/BootScene.ts`
