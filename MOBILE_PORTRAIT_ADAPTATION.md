# Мобильная адаптация под вертикальный вид

## Обзор изменений (обновлено 2026-07-27)

Реализована **полная мобильная адаптация** пользовательского интерфейса для портретного режима с большими кнопками, центрированным заголовком и оптимизацией для сенсорных экранов. Все изменения изолированы внутри условий `if (layout.isPortrait)`, что гарантирует сохранение PC-версии без изменений.

## Ключевые улучшения мобильной версии

### Размеры кнопок (touch-friendly)
- **Основные действия**: 80% ширины, 64px высота
- **Навигация**: 32% ширины, 52px высота
- **Списки**: 78% ширины, 58px высота
- Все кнопки превышают минимум 44×44px для iOS/Android

### Типографика
- Заголовки: 38-40px (было 34-36px)
- Кнопки: 24-26px (было 20-22px)
- Информация: 24-28px (было 20-24px)
- Описания: 22-24px (было 18-20px)

### Отступы и панели
- Панели: 88% ширины (было 86%)
- Отступы между кнопками: ~9-10% высоты экрана
- Использование `layout.padding` для консистентности

## Как это работает

```typescript
const layout = getResponsiveLayout(this);

if (layout.isPortrait) {
  // Портретный layout с большими кнопками
  const btnWidth = layout.width * 0.8;
  addTextButton(this, cx, y, "Текст", callback, { 
    width: btnWidth, 
    height: 64, 
    fontSize: "24px" 
  });
} else {
  // Ландшафтный layout (оригинал)
  addTextButton(this, x, y, "Текст", callback, { width: 300 });
}
```

## Тестирование

### В браузере (Dev Tools)
1. `npm run dev`
2. F12 → Toggle device toolbar
3. Выбрать устройство или задать размер:
   - **Портрет**: 720×1280 или iPhone SE (375×667), Galaxy S20 (360×800)
   - **Ландшафт**: 1280×720 или Desktop

### На реальном устройстве
1. `npm run build`
2. Загрузить `dist/` на тестовый сервер
3. Открыть на телефоне
