# Реализация игровых сцен Phaser

Документ фиксирует результат этапа 5 из `PHASER_YANDEX_MIGRATION_PLAN.md`.

## Итог

Реализованы основные игровые сцены web-версии:

- `BootScene` - инициализация SDK и загрузка сохранения.
- `PreloadScene` - загрузка изображений машин и экран прогресса.
- `MenuScene` - главное меню, баланс, гараж, шанс, очки, pending-награда.
- `SpinScene` - обычный спин, короткая анимация, pending-карточка, оставить/продать.
- `GarageScene` - сетка гаража, страницы, карточка выбранной машины, продажа.
- `CasesScene` - обычные и эксклюзивные кейсы, x1/x10/x100, summary массового открытия.
- `UpgradesScene` - улучшение шанса и гаража с disabled-состояниями.
- `LeaderboardScene` - отправка score и fallback для локального режима.

## UI-компоненты

Обновлены UI-хелперы:

- `buttons.ts` - кнопки с размерами, цветами и disabled-состоянием.
- `layout.ts` - заголовок сцены, кнопка назад, панели, информационный текст.
- `carCard.ts` - карточка машины с изображением и цветом редкости.

## Проверка

Выполнена production-сборка:

```text
npm run build
```

Результат:

```text
✓ built
```

Предупреждения Vite не блокируют сборку:

- внешний `/sdk.js` не бандлится;
- Phaser-бандл больше 500 kB.
